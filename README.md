## ✨ Características Principales

- 🛠️ **22 Herramientas Gratuitas**: Cobertura para Marketing, Finanzas, Ventas, Legal, Operaciones y Productividad.
- 💻 **Instalación de Escritorio Nativa (PWA)**:
  - **Windows (Chrome / Edge / Brave)**: 1-clic para instalar en el Escritorio y Menú Inicio.
  - **macOS (Chrome / Edge / Safari Sonoma+)**: Compatible con `/Applications` y *"Agregar al Dock"*.
  - **Standalone Mode**: Ventana independiente, sin distracciones ni barras de navegador.
- ⚡ **Modo Offline & Caching**: Service Worker integrado con precacheo de recursos críticos.
- 🎨 **Diseño Moderno y Responsivo**: Interfaz fluida adaptada a cualquier tamaño de pantalla con soporte para modo oscuro.

## 🌐 Despliegue en GitHub Pages

Este proyecto está 100% optimizado para GitHub Pages con rutas relativas:

1. Ve a la pestaña **Settings** de tu repositorio en GitHub.
2. En la barra lateral izquierda, haz clic en **Pages**.
3. En **Build and deployment > Source**, selecciona **Deploy from a branch**.
4. En **Branch**, selecciona `main` y la carpeta `/ (root)`.
5. Haz clic en **Save**. En un par de minutos tu sitio estará en vivo en:
   ```
   https://juanxaviercasa.github.io/herramientas-pymes/
   ```

## 💻 Ejecución Local

Puedes probar la aplicación localmente usando cualquier servidor estático:

```bash
# Con Node.js / npx
npx serve .

# O con Python 3
python -m http.server 8000
```
